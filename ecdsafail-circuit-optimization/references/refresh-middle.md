## Evidence and outcome discipline

The official score uses the rounded average executed Toffoli count multiplied by the referenced physical width. Allocator peak live count can differ from `max referenced qubit ID + 1`; the Q1263 campaign measured and corrected that distinction. A count-only constructor or generation manifest is a resource estimate, not a correctness receipt. Some Q823 manifests explicitly say `COMPLETE_GENERATION_UNVALIDATED` even though the separate official submission later has measured metrics.

Read `rejected` with its reason. A scored source rejected for failure to improve the scalar product can be a successful regional Q/T or Q-cap frontier result. A `failed` source with no official metrics is unqualified by the platform; a note-reported clean developer run does not change that status. Timeouts and upload failures do not by themselves establish arithmetic mismatches. Confirm failure causes from workflow evidence before treating a note's diagnosis as official.

Every op-stream edit changes the Fiat–Shamir corpus. Same nonce across different streams is not a paired experiment. Frozen inputs and simulator coins support paired regression analysis, while the actual new serialized source requires its own complete evaluator result. An unchanged failing-shot set on a finite corpus is stronger regression evidence than a noisy mean comparison, but remains finite evidence.
